# v0.5.0 — Local-rule lifecycle and NTPC provenance

Release date: 2026-08-28

## Scope

This release implements the first safe slice of issue #18 for New Taipei local interior-renovation rules. It does not enable Taipei or Taoyuan and does not include the three central-law pending snapshots tracked in #16.

## Changed

- Added a local-rule lifecycle contract with `active`, `abolished`, `superseded`, and `pending_reverification` states.
- Separated legal-event dates (`promulgated_at`, `effective_from`, `effective_to`, `amended_at`) from retrieval and verification timestamps.
- Added fail-closed version selection for unknown effective dates, overlapping versions, invalid dates, and pending reverification.
- Corrected NTPC official identifier `C0170020` provenance: promulgation is recorded as `2011-04-25`; unverified effective/amendment dates are no longer synthesized.
- Added point-level normalized requirements for NTPC points 7–11 covering document evidence, simple filing, conditional fire documentation, deadlines, and escalation.
- Preserved `簡易申報` as the canonical official term while keeping `簡易室內裝修` as a compatibility alias.
- Downgraded the generic New Taipei e-service homepage to `discovery_reference`; it is not requirement evidence without a stable service/form identifier.
- Added lifecycle acceptance and regression tests.

## Safety behavior

- A current active source can be discoverable without claiming a historical effective interval.
- Historical `as_of_date` selection fails closed while `effective_from` is unknown.
- `pending_reverification` blocks selection.
- Abolished records are never selected as current.
- Overlapping historical versions require human review instead of automatic selection.
- Normalized requirement hashes detect silent fact changes.
